# 01-demo

Simple HTML/CSS/JS learning page for exploring OpenCode. No build tools, no test runner, no package manager.

## Quick start

```bash
open index.html          # macOS
# or just double-click index.html
```

## Stack

- Vanilla HTML, CSS, JS in `index.html`
- README mentions Tailwind CSS but it is **not installed or configured** — do not assume a CDN or build step exists
- Add Tailwind via CDN script tag if/when needed; there is no `package.json` or bundler

## Conventions

- README is in Spanish, code comments/commits can be in either language
- Single-page app — all work happens in `index.html`
